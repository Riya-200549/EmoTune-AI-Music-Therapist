# EmoTune - AI Music Therapist 🎵

## Project Overview

EmoTune is an AI-powered music recommendation system that detects a user's emotion from facial expressions and recommends suitable songs based on the detected mood.

The system uses Deep Learning and Computer Vision techniques to analyze emotions and provide personalized music suggestions.

---

## Features

- 📷 Image Upload Emotion Detection
- 🎥 Live Webcam Emotion Detection
- 😊 Detects Human Emotions
- 🎵 Recommends Songs Based on Emotion
- 🤖 Deep Learning Model Integration
- 🌐 User-Friendly Web Interface

## How to Run

1. Clone the repository

```bash
git clone https://github.com/Riya-200549/EmoTune-AI-Music-Therapist.git
```

2. Install dependencies

```bash
pip install flask tensorflow opencv-python numpy
```

3. Run the application

```bash
python app.py
```

4. Open browser

```text
http://127.0.0.1:5000
```
